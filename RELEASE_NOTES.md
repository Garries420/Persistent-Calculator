# Persistent Calculator 2.0.1

Version 2.0.1 replaces the hand-built Standard, Scientific, and Programmer symbols with the exact Calculator Fluent Icons from Microsoft's open-source Calculator project.

Programmer now has separate Full keypad and Bit toggling keypad controls with clear hover labels. Open calendars, date amount lists, and converter pickers can now be dismissed by clicking anywhere outside them.

Download `PersistentCalculator.exe` and run it directly—no installer is required.
